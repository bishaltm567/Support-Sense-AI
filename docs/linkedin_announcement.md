# LinkedIn announcement draft

I built SupportSense AI, a local-first customer-support RAG demo designed to explore how Databricks can support a governed data-to-AI workflow.

The prototype uses fictional FAQs, source citations, explicit abstention when evidence is missing, server-side access filtering, and a small adversarial evaluation suite. Its baseline runs locally without cloud credentials or an LLM, while Databricks notebooks show an optional Delta ingestion path.

One important design choice: a passing demo test suite is not a security certification. The project documents what was tested, what requires a real Databricks workspace, and why cloud costs remain unknown until measured.

I’m looking forward to sharing the architecture, live demo, and lessons learned with the Kathmandu Databricks community.
