# Five-minute presentation outline

| Time | Topic | Key message |
|---|---|---|
| 0:00–0:35 | Problem | Support answers should be useful, sourced, and honest when the knowledge base has no answer. |
| 0:35–1:15 | Why Databricks | Delta and notebooks provide a path from reproducible local data preparation to governed cloud data; advanced serving/vector features are optional. |
| 1:15–2:00 | Architecture | CSV/JSON → validation and access filtering → lexical retrieval → grounded answer and citations → privacy-minimized operational metadata. |
| 2:00–3:15 | Live demo | Refund policy, unknown discount, direct injection, malicious retrieved content, and access-control fixture. |
| 3:15–4:00 | Security/evaluation | Show current measured tests; explain the scope limits and why prompt-only defense is inadequate. |
| 4:00–4:35 | Cost and lessons | Local mode has no cloud inference; cloud cost is unknown until measured in a workspace. Not every free-tier supports every component. |
| 4:35–5:00 | Next steps | Workspace validation, identity-aware authorization, production data governance, vector retrieval comparison, and human review. |
